# Agents Documentation Directory

This directory provides developer and AI agent documentation for the **Clean Blog Jekyll** project.

The primary configuration and detailed architectural guidelines are maintained in the workspace customization root at `.agents/`:

- [AGENTS.md](../.agents/AGENTS.md) — Main entry point, project overview, guidelines, and commands.
- [codebase_structure.md](../.agents/codebase_structure.md) — Technical breakdown of layouts, includes, Liquid components, and config.
- [styles_and_ui.md](../.agents/styles_and_ui.md) — Sass pipeline, design tokens, typography, color palette, and UI components.
- [content_and_posts.md](../.agents/content_and_posts.md) — Post schema, frontmatter spec, page creation, and Formspree form integration.
