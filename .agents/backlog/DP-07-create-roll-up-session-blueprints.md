## Task
Write ready-made practice session plans that combine drills from the pack, so bowlers don't have to choose which drills to pair.

## Context
- Example blueprints from the plan: "The 45-Minute Pre-Match Lead Tune-Up", "The Skip's Pressure Conversion Session", "The Two-Player Competitive Roll-Up".
- Cover all three durations (30, 45, 60 minutes), mix solo and pairs, and cover different positions (Lead, Second, Third, Skip, Singles).
- Each blueprint should list: goal, drills in order, ends or time per drill, target scores, and a short warm-up/cool-down note.
- These durations match the `#ai-duration` options in the AI Prompt Builder (`_includes/ai-prompt-builder.html`), so the two could cross-link.
- Same delivery options and noindex guidance as DP-06.
